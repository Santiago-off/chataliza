Agradecimientos

Chataliza no se apoya en librerías de pago ni servicios de terceros. Existe gracias a documentación y estándares abiertos.

WHATWG y W3C

Por especificar HTML, CSS y las APIs web (File API, Drag and Drop, Canvas, Compression Streams) que hacen posible leer, comprimir y dibujar todo esto sin salir del navegador.

MDN Web Docs

La referencia que se ha consultado para cada API usada en app.js: del formato de DecompressionStream a las propiedades Unicode de las expresiones regulares.

Unicode Consortium

Por mantener las propiedades de carácter (Extended_Pictographic) que permiten detectar emojis de forma fiable con una expresión regular, sin listas manuales interminables.

Schema.org

Por el vocabulario que usa esta web para describirse a los buscadores: WebApplication, WebSite, BreadcrumbList y FAQPage.

La comunidad de quienes exportan y comparten sus chats

A quienes prueban Chataliza con sus propias conversaciones y mandan comentarios para mejorar el análisis. Ningún dato de esas pruebas se guarda ni se comparte: solo llega el mensaje que decidís enviar.
